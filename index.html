Aria Documentation

A unified Android client for Navidrome, Jellyfin, Emby, Audiobookshelf, and local storage. Direct client-to-server connectivity with zero cloud telemetry.

Free Local Player $4.99 One-Time Server Unlock No Subscriptions ExoPlayer / Media3 Engine Android Auto Built-in

01 Overview

Aria is an independent audio player for Android designed specifically for personal media server operators. It bridges the gap between music streaming servers and dedicated audiobook servers by combining both libraries into one responsive playback interface.

Aria contains no middleman servers, cloud databases, or tracking infrastructure. Your phone connects straight to your server instances, and all authentication tokens stay sandboxed on your device.

Navidrome & Subsonic

Music streaming, album/artist navigation, server playlists, caching, and native Subsonic scrobbling.

Jellyfin & Emby

Full audio catalog playback, search, and playback session reporting. Video libraries are strictly filtered out.

Audiobookshelf

Chapter markers, bookmarks, sleep timers, and bidirectional progress synchronization.

Local Device Storage

Comprehensive offline player for local music collections and standalone M4B/MP3 audiobook files.

03 Quickstart: Adding a Server

  1. Open Settings via the gear icon in the main navigation bar.
  2. Under Media Providers, tap Add Media Provider.
  3. Select your server backend from the dropdown menu (Navidrome / Subsonic, Jellyfin, Emby, or Audiobookshelf).
  4. Enter your server URL including protocol and port (e.g. http://192.168.1.50:4533).
  5. Enter your server username and password, then tap Add or Login.
  6. Once authenticated, Aria immediately begins synchronizing library indexes in the background.

04 Server Setup Specifications

Navidrome & Subsonic-Compatible Servers

Aria implements the Subsonic REST API (spec 1.16.1) using modern salt and MD5 token authentication.

  • URL Format: http://[host]:[port] or https://[domain] (e.g., http://192.168.1.50:4533).
  • Authentication: Username and plaintext password (the app computes token = md5(password + salt) for network calls).
  • Verification: The app executes a test query to /rest/ping. On success, the UI displays Status: ok.

Jellyfin (Audio Only)

Connects via the Jellyfin REST API. Non-audio collections (movies, TV shows, photos) are filtered out.

  • URL Format: http://[host]:8096 or https://jellyfin.example.com.
  • Authentication: Authenticates via POST to /Users/AuthenticateByName. Aria receives and persists an access token and user GUID.
  • Verification: The connection status reads Connected — continue. Tap Continue to load audio libraries.

Emby (Audio Only)

Uses Emby's native client authorization protocol (sending both X-Emby-Token and X-MediaBrowser-Token for maximum version compatibility).

  • URL Format: http://[host]:8096 or https://emby.example.com.
  • Authentication: Username and password via POST /Users/AuthenticateByName.
  • Verification: The UI verifies authorization and prompts Connected — continue.

Audiobookshelf

Aria connects directly to your Audiobookshelf server's REST API to stream audio, fetch chapter marks, and update listening positions.

  • Location in App: Navigated to via Settings > Audiobooks > Audiobookshelf.
  • URL Format: http://[host]:13378 or https://audiobooks.example.com.
  • Authentication: POST to /login returning a Bearer authentication token.
  • Verification: Displays a toast confirmation: Audiobookshelf connected.

05 Local Files & Storage Access

Aria functions as a high-performance standalone player for audio files stored on device storage or microSD cards.

  • Supported Codecs: FLAC, MP3, AAC, Opus, WAV, OGG, and M4B/M4A containers.
  • Android 13+ Permissions: Requests READ_MEDIA_AUDIO for MediaStore scanning.
  • Legacy Android Permissions: Requests READ_EXTERNAL_STORAGE on Android 12 and earlier.
  • Background Notifications: Requests POST_NOTIFICATIONS to manage lock screen media controls.
  • Storage Access Framework (SAF): Supports granting permanent read access to custom external folders or selecting individual .m4b files via the system picker.

06 Remote Access & Proxy Configurations

Aria does not provide hosted relay servers. Remote access depends on your personal network configuration:

Encrypted VPN Mesh (Best)

Connect via Tailscale, WireGuard, or OpenVPN. Enter your server's internal VPN IP (e.g., http://100.64.0.12:4533). Zero port forwarding and no public SSL headaches.

Reverse Proxy (HTTPS)

Caddy, Traefik, Nginx, or Cloudflare Tunnels with a globally recognized SSL certificate (such as Let's Encrypt).

Authenticating Reverse Proxies (Authelia, Authentik, Cloudflare Access): Aria does not support injecting arbitrary custom HTTP headers (such as Remote-User) or browser-based SSO redirects. If your reverse proxy requires forward-auth, Aria cannot authenticate. You must configure bypass rules in your proxy for Aria's API paths or connect through a VPN.

07 Certificates, SSL & LAN HTTP

  • Plain HTTP and LAN IPs: Fully supported. Cleartext HTTP traffic is explicitly enabled in AndroidManifest.xml (android:usesCleartextTraffic="true") and network_security_config.xml.
  • Public HTTPS: Fully supported when backed by a recognized CA (e.g. Let's Encrypt).
Self-Signed Certificates Do Not Function for Playback or Downloads: While certain REST metadata endpoints previously contained trust-bypass logic, the underlying ExoPlayer media engine (DefaultDataSource) and download workers utilize Android's native HttpURLConnection. Because Android enforces system trust anchors, audio streams and offline downloads over self-signed HTTPS will fail with SSLHandshakeException.

User-Installed CAs: Android ignores user-installed root CAs in release builds because <certificates src="user" /> is restricted to debug builds.

Recommended Solution: Use plain HTTP over WireGuard/Tailscale, or obtain a valid Let's Encrypt certificate.

08 Offline Downloads & Caching

Streaming Cache (250 MB LRU)

ExoPlayer maintains a 250 MB Least-Recently-Used disk cache in media_stream_cache_v2. When streaming on unmetered connections, it pre-caches the first 1 MB of upcoming queue items for instantaneous skip playback.

Image Cache (250 MB)

Managed by Coil in image_cache to store album artwork and artist portraits without re-downloading.

Offline Downloads:

  • Music Tracks & Albums: Downloaded to internal app sandbox storage at music_downloads/ (indexed via downloads_index.json).
  • Audiobooks: Audiobookshelf books are downloaded into audiobooks/.
  • Wi-Fi Only Toggle: In Settings > Downloads, toggle Wi-Fi only to prevent downloads on cellular data. When on mobile data, download jobs pause with the status Waiting for Wi-Fi.

09 Audiobook Engine & Synchronization

Aria provides specialized playback ergonomics for long-form spoken-word audio:

  • Chapter Navigation: Automatic parsing of embedded M4B chapter tags and Audiobookshelf server chapters.
  • Playback Speed: Fine-grained adjustment from 0.5x to 2.0x in 0.1x increments.
  • Bookmarks: Create named bookmarks with saved timestamps.
  • Per-Book Memory: Position, duration, and completion states are stored independently per book.

Auto-Rewind on Resume

When resuming playback, Aria automatically rewinds a small interval to restore listening context, clamped so it never crosses the current chapter boundary:

Elapsed Pause Time Rewind Offset Boundary Constraint
< 10 seconds 0.0s (Instant resume) N/A
10 seconds – 1 minute 3.0s Clamped to chapter start
1 minute – 5 minutes 10.0s Clamped to chapter start
5 minutes – 30 minutes 20.0s Clamped to chapter start
> 30 minutes 29.5s Clamped to chapter start

Audiobookshelf Two-Way Sync

  • Client to Server: Progress updates sync on pause, stop, track end, and periodically via a background sync heartbeat.
  • Server to Client: When resuming playback after being paused for 10 seconds or longer, Aria queries Audiobookshelf. If another device advanced the position and the server record is newer, Aria updates its position to match the server.

10 Android Auto Integration

Aria implements Android's modern Media3 MediaLibraryService for vehicle head units:

  • Dashboard Navigation: Access Home, Albums, Songs, Artists, Playlists, and Audiobooks directly from the vehicle dashboard.
  • Source Switching: Select the Sources menu on the car screen to switch between Local Storage, Local Audiobooks, Navidrome, Jellyfin, Emby, and Audiobookshelf.
  • Audiobook Controls: Dedicated 15-second skip backward and 30-second skip forward buttons.
  • Licensing Behavior: While Pro is locked, remote servers display an informational placeholder item (Unlock Pro on your phone to play remote libraries), while local music and local audiobooks remain fully playable.

11 Privacy & Network Destinations

Zero Telemetry: Aria contains no analytics SDKs, behavioral tracking, crash reporting services, or advertising frameworks (no Google Firebase, no Sentry, no Mixpanel).

Credential Isolation: Server passwords, usernames, and authentication tokens are stored exclusively in the app's sandboxed private storage (Context.MODE_PRIVATE in SharedPreferences). They are never transmitted to any third-party server.

Outbound Network Requests: Traffic is strictly confined to:

  1. Your Configured Servers: For media streaming, metadata, and progress syncing.
  2. Google Play Services: Play Billing (to verify Pro license purchases) and In-App Review.
  3. Artist Artwork Fallback: When an artist portrait is missing locally and on your server, ArtistArtworkManager.kt queries api.deezer.com and itunes.apple.com to resolve artist portraits.

12 Troubleshooting & Diagnostics

"Wrong username or password"

Subsonic: Subsonic uses token-based MD5 authentication. Ensure your user account has streaming permissions enabled in the Navidrome/Subsonic server settings.
Jellyfin/Emby: Verify you can log in through the web UI using the exact same username and password.

"SSL error — check server URL or cert"

The server is using an untrusted or self-signed SSL certificate. Connect over plain HTTP via VPN or obtain a certificate signed by a recognized Certificate Authority (e.g. Let's Encrypt).

"Can't reach server — check the URL"

Ensure the URL includes http:// or https:// and the explicit port number (e.g., :4533, :8096, :13378).

HTTP 301 / 302 Redirection Loops

Check reverse proxy trailing-slash rules. Ensure POST endpoints (such as /login) are not rewritten as GET requests during reverse-proxy redirects.

14 Architectural Findings & Edge Cases

External Artwork Lookup Opt-Out: ArtistArtworkManager.kt queries api.deezer.com and itunes.apple.com when artist portraits are missing. While a setting exists for Online artist artwork (strings_settings.xml:18), self-hosters running strict firewall rules should note that missing artist portraits will generate outbound DNS/HTTPS requests.
Backup Security: The settings export utility (MusicBackup.kt) writes server URLs, usernames, passwords, and tokens into a plaintext JSON file. Users should keep their exported backup files in a secure location.
